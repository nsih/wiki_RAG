## 3. 결정 기록

되돌릴 때 이유를 알기 위해 남긴다.

| 날짜 | 결정 | 이유 |
|---|---|---|
| 2026-09-09 | 파인튜닝 대상 = **임베딩 모델** | 이 서버 CPU에서 실제로 돌아가고, 검색 품질이라는 측정 가능한 목표가 있음 |
| 2026-09-09 | 학습은 **이 서버**에서 수행 | 91.44는 SSH 22번 차단 → 원격 학습 자동화 불가. `/v1` API만 열려 있어 데이터 생성용으로만 사용 |
| 2026-09-09 | `peft`·`datasets`·`accelerate` **사용 안 함** | 배우는 게 목적인데 추상화 계층이 개념을 가림. 순수 PyTorch 루프로 작성 |
| 2026-09-09 | torch **재설치 안 함** | cu130 빌드도 CPU로 정상 동작. CPU 전용으로 바꾸면 디스크 4 GB 회수되나 지금 이득 없음 |
| 2026-09-09 | 작업 브랜치 **생성 안 함** | 사용자가 직접 커밋 진행 중이었음. 커밋 완료 후 결정 |
