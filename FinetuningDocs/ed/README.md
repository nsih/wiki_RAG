## 기록 규칙

- **실측값을 남긴다.** 일반론보다 "이 서버에서 재보니 4.42 ms"가 훨씬 오래 기억에 남는다.
  측정 명령도 함께 적어 나중에 재현할 수 있게 한다.
- **틀렸던 이해를 지우지 않는다.** "이렇게 이해했는데 실제로는 이렇더라"를 표로 남긴다.
  개념이 자리잡는 건 오해를 교정하는 순간이다.
- **이 프로젝트와 연결한다.** 개념 설명으로 끝내지 말고
  "그래서 `train_embedder.py`에서 이렇게 쓴다"까지 적는다.
